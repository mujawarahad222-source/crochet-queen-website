# Crochet Queen Website

A responsive, animated crochet product storefront built with plain HTML, CSS and JavaScript for GitHub Pages.

## Before launch
- Replace sample products, sample prices and sample photos with real product details.
- Add real Amazon product URLs in each product's `amazonUrl` field.
- Set `STORE.whatsappNumber` to your WhatsApp number in international format, digits only.
- Test product images, shopping links and mobile layout.
- Do not publish placeholder prices or links as if they were real.

## Hosting
This static website can be published using GitHub Pages. GitHub Pages does not process payments or store orders.
